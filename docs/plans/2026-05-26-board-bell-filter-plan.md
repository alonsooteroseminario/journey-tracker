# Plan: Board Bell Filter (reminderEnabled quick filter)

Generated by /plan-eng-review on 2026-05-26
Branch: main

## Problem Statement

Users need a fast way to see all tasks/substeps with daily reminders enabled
on the Board page. No visual indicator exists on KanbanCard; no filter chip
exists in KanbanFilters.

## Decisions

- **D1 (Goals level behavior):** Bubble up — show goals containing at least one
  reminder-enabled non-completed task/substep when bell filter is active.
- **D2 (KanbanCard badge):** Add 🔔 chip to KanbanCard metadata row for tasks
  and substeps with `reminderEnabled=true`.
- **D3 (Test scope):** `KanbanFilters.test.tsx` + `KanbanCard.test.tsx`.
  KanbanBoard filter predicate not tested (complex mock setup, 4-line predicate).
- **D4 (Substep reminders at goals level):** Check both `task.reminderEnabled`
  AND `substep.reminderEnabled` nested within each task.

## Filter Logic Diagram

```
filteredData useMemo (KanbanBoard.tsx)
│
├── archive filter   (show only archived OR hide archived)
├── search filter    (title match)
├── priority filter  (tasks level only)
├── date filter      (tasks level only)
├── doneToday filter (completedAt date match)
└── reminderOnly filter [NEW]
     ├── goals level → .some(t => t.reminderEnabled || t.substeps?.some(s => s.reminderEnabled))
     │                          && t.status !== "completed" && !t.isArchived
     └── tasks/substeps → item.reminderEnabled
```

## NOT in scope

- Persisting `reminderOnly` state to localStorage (consistent with existing
  doneToday/dateFilter behavior — none are persisted)
- Showing reminder count badge on goal cards (e.g., "3 reminders")
- KanbanBoard filter predicate tests (complex DnD + RTK Query mock overhead)

## Failure modes
